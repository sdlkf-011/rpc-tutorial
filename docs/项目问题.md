# 问题集合

## 1.日志模块（spdlog）

1.1 为什么选择 spdlog 而不是 glog 或 log4cpp？它的异步日志机制如何实现？
1.2 多线程环境下如何避免日志竞争？如何配置日志滚动策略？
1.3 日志级别动态调整如何实现？如何保证日志写入不影响 RPC 性能？日志分级策略（Debug/Info/Warn/Error）的实际应用场景是什么？

## 2.负载均衡模块

2.1 实现了哪些负载均衡算法（轮询/加权/一致性哈希）？如何动态感知节点负载变化？
2.2 如何避免雪崩效应？如何与 Zookeeper 协同实现服务发现？

## 3.压缩模块

3.1 选择 zlib、Snappy 还是 zstd？如何权衡压缩率与速度？
3.2 如何判断何时启用压缩（如数据阈值）？压缩失败如何处理？
3.3 压缩与加密的顺序为何重要？你的设计顺序是什么？

## 4.加解密模块

4.1 使用对称加密（AES）还是非对称加密（RSA）？
4.2 密钥如何管理？如何防止重放攻击？加密算法性能如何测试？
4.3 如何处理加密数据损坏或解密失败？

## 5.序列化与反序列化

5.1 为何选择 Protobuf、JSON？如何实现跨语言兼容？
5.2 如何处理字段增删导致的版本兼容问题？自定义序列化如何优化性能？

## 6.Zookeeper节点注册

6.1 为何选择 Zookeeper 而非 ETCD？临时节点和持久节点的区别？

## 7.RPC协议定义

7.1 如何设计协议头（Magic Number/Version/MsgID/Length）？如何解决粘包拆包？

## 8.网络管理模块

8.1 使用 Reactor 还是 Proactor 模式？如何实现高并发（epoll+线程池）？

## 9.综合架构设计

9.6 用到了哪些性能调优方法？
